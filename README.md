# Winevent 
一个Windows的小工具<br>
有作者于2025年2月分创建的一个作品，正式提交github的日期是2024 4 5<br>
整个代码都是由python编写而来。<br>
文件主体一共有4个文件1个文件夹构成：`__pycache__`、Main_calculate.py、Main_window.py、README.md、start.cmd。<br>
pycache是存放python生成的字节码编译文件的，<br>
Main_calculate是存放函数的，<br>
Main_window.py是创建窗口用的，<br>
README.md是程序说明，<br>
start.cmd是用于以管理员权限运行程序的cmd（Windows）命令。<br>
